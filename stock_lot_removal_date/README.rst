This module provides the following features:

-  Formats the display name of lots or serial numbers as "[yyyy/mm/dd]
   Lot Name", showing the removal date in the "yyyy/mm/dd" part.
-  Makes lots searchable by their removal date string.

Configuration
=============

Set the timezone on the Company’s partner to control how the Removal DT
Date on lots/serials is computed from the Removal Date (datetime). If no
timezone is set, the Japan timezone is used by default.

The OCA partner_tz module can be used to display the timezone field on
the partner form.
